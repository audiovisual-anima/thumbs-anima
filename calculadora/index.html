Como ler. Custo direto = soma dos módulos ligados. Custo real = custo direto ÷ (1 − falhas) ÷ (1 − devoluções): se 8% das impressões se perdem, cada peça boa carrega o custo das que falharam. Preço base = custo real × markup (+ urgência, se ligada); é o que entra no seu bolso por peça. O anúncio de cada canal = (preço base + frete + taxa fixa) ÷ (1 − comissão − pagamento − tributo por %). No MEI o DAS é fixo por mês, então ele entra como custo rateado pelas peças vendidas — não como porcentagem. O teto do MEI só gera aviso, nunca trava nada.
